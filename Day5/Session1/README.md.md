# ThinkBridge Training

This repo contains my session work and notes.

## Basics

###  HTML
- Structure of web pages  
- Example: `<h1>Title</h1>`, `<p>Paragraph</p>`

###  CSS
- Styles the page (colors, fonts, layout)  
- Example: `h1 { color: blue; }`

###  JavaScript
- Adds logic and interactivity  
- Example: `alert("Hello!");`

###  Git
- Version control (track and share code)  
- Common:  
  - `git add .` → stage changes  
  - `git commit -m "msg"` → save  
  - `git push` → upload
