Web Development & Git Basics 
HTML Basics

HTML means HyperText Markup Language.

It is used to create the structure of a webpage.

It contains elements like:

Headings (titles)

Paragraphs (text content)

Links (to move between pages)

Images

Lists (ordered and unordered)

Containers (to group content)

CSS Basics

CSS means Cascading Style Sheets.

It is used to style webpages (colors, fonts, layout).

Three ways to use CSS:

Inline → style directly inside the HTML tag.

Internal → style written inside the HTML file in the head section.

External → style written in a separate file and linked to the HTML file.

Git & GitHub Basics
Git

A tool used for version control (tracking changes in code).

Helps developers save different versions of their project.

GitHub

A website where you can store your code online.

Allows you to share projects and work with a team.

Basic Git workflow

Initialize Git in your project folder.

Add files to Git.

Save changes with a commit message.

Connect your local project to GitHub.

Push (upload) your changes to GitHub.

How to create a GitHub repository

Log in to GitHub.

Click on "New Repository".

Enter a name for your project.

Choose Public or Private.

Click "Create Repository".

VS Code Basics

Visual Studio Code (VS Code) is a code editor.

You can write, edit, and run code here.

Key features:

Extensions (add tools like Live Server, Prettier).

Terminal (run commands inside VS Code).

Debugging (find and fix errors).

File Explorer (see all your project files).

Useful Shortcuts

Open Terminal → Ctrl + ~

Toggle Sidebar → Ctrl + B

Comment a line → Ctrl + /

Open Command Palette → Ctrl + Shift + P
